01 / Sobre

Quem sou

Meu dia a dia é provedor de internet: atendimento, ordens de serviço, técnicos na rua, painéis nas torres, concentrador PPPoE, monitoramento. Foi aí que comecei a programar — porque cada problema da operação parecia pedir uma ferramenta que ainda não existia.

Prefiro entender as coisas desde a base em vez de depender de geradores e templates. Quando um roteador não aceita login por script, abro o JavaScript dele e descubro como a autenticação funciona. Quando quero aprender uma linguagem nova, escolho um problema real da rede e resolvo com ela.

Atualmente trabalho com desenvolvimento web full-stack, infraestrutura de rede e automação.

02 / Projetos

O que eu construí

Gestão de provedor

Sistema de gestão para provedor

Plataforma de gestão operacional para provedores de internet: ordens de serviço e atendimentos, painel de técnicos, financeiro, estoque e controle de entrega de carnês. Integração com MK-Auth, phpIPAM, MikroTik e Zabbix, e mapa da rede com torres e enlaces PTP exibindo o status de cada link em tempo real. A equipe de campo acessa pelo aplicativo PWA.

Em evolução contínua: backend em migração de Node.js para Go, nova interface e implantação em contêineres no Proxmox.

Go TypeScript PostgreSQL Zabbix API Electron

Automação de rede

Configurador automático de roteadores e antenas

Ferramenta de bancada para TP-Link Archer C20: detecta o roteador, faz login, atualiza o firmware, espera o reboot, aplica a configuração padrão e confere o resultado — sozinha, um aparelho atrás do outro.

Também inclui um sistema de automação para atualização de firmware e configuração de antenas Intelbras APC e Ubiquiti.

Go Python TP-Link Intelbras · Ubiquiti

Pedidos online

Sistema de pedidos para sorveteria

Plataforma de pedidos online: página inicial da loja, cardápio com montagem do pedido e escolha de sabores, e painel administrativo para o lojista atualizar a página inicial, os preços e os sabores disponíveis.

Go PostgreSQL React · TSX Vite

Outros

Buscador de preços de antenas

Ferramenta de cotação que pesquisa anúncios de antenas em marketplaces, identifica kits, calcula o preço por unidade e filtra as ofertas pelos modelos e valores-alvo da compra.

Python FastAPI web scraping
